# Creative Garage v4

Site HTML/CSS/JavaScript com painel administrativo em PHP e conteúdo em JSON.

## Testar localmente no XAMPP

1. Copia a pasta `creative-garage-v4` para `C:\xampp\htdocs\creative-garage-v4`
2. Liga o Apache no XAMPP
3. Abre: `http://localhost/creative-garage-v4/`
4. Admin: `http://localhost/creative-garage-v4/admin/login.php`

Login inicial:

- Utilizador: `admin`
- Password: `admin123`

## Hospedagem

Envia a pasta inteira por FTP. A hospedagem precisa suportar PHP.

As pastas `data/` e `assets/uploads/` devem ter permissão de escrita para o PHP conseguir guardar alterações.

## Conteúdo

O painel admin edita:

- Conteúdo geral
- Serviços
- Galeria
- Parceiros
- Contacto

As imagens atuais são ilustrativas por URL. Podes trocar depois por imagens reais.
